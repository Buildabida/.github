# Hi, we're Buildabida

We're team LT2 in the FTW Foundation Data Engineering Track, 2026. For our capstone, we track public works projects in the Philippines: every project, every peso, every place.

## What we're building

**[infra-project-monitoring](https://github.com/Buildabida/infra-project-monitoring)** is a Databricks pipeline. It joins DPWH project records with PSGC place codes and the 2024 census. Then it shows where public works money goes, and which places get too little for how many people live there.
